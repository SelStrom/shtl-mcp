# TASK: set_selection принимает asset-path

**Status:** in review
**Тип:** code (без raw-diff): намерение не меняется — F3/AC3.1 уже требует
`set_selection`, форма target'а — деталь реализации, приведённая к общей.
**Привязка:** F3 (AC3.1, AC3.4), wiki/command-set.md §Сцена / иерархия / объекты.

## Проблема

`set_selection` резолвил строку только как объект текущего контекста
(`SceneObjects.Resolve`), поэтому asset-path уходил в `missing`. Соседние тулы к тому
моменту уже принимали три формы target'а — объект контекста, asset-path, instanceId
(AC3.11), — и `set_selection` остался единственным исключением.

Практическое следствие: выделение — это вход для тех действий редактора, у которых
другого API нет. `execute_menu_item` исполняет `MenuItem`, работающие по
`Selection.objects` (импорт-настройки, контекстные операции над ассетом), а показать
ассет человеку в Project-окне тоже можно только выделив его. Ни то, ни другое не было
достижимо для ассета: оставался `run_csharp` — footgun-тул, выключаемый конфигом,
ради одной строки `Selection.objects = new[]{ LoadAssetAtPath(...) }`.

## Решение

В `SetSelectionTool.Invoke` резолв стал двухступенчатым: объект контекста, иначе
`AssetDatabase.LoadAssetAtPath<Object>(name)`; не нашлось ни то ни другое — как и
раньше, строка попадает в `missing`. Приоритет у объекта контекста: имена сцены и
пути ассетов лежат в разных пространствах, а порядок сохраняет прежнее поведение для
всех вызовов, которые работали до правки.

Описания тула и схемы обновлены (AC3.4) — иначе новая форма target'а не видна в
`tools/list` и модель ей не воспользуется.

## Acceptance

- **A1** — Строка-asset-path выделяет ассет (`selected: 1`, `Selection.objects[0]` —
  загруженный ассет).
- **A2** — Строка, не найденная ни как объект контекста, ни как ассет, попадает в
  `missing`, `selected` её не считает.
- **A3** — Прежнее поведение для объектов сцены не изменилось.
- **A4** — `tools/list` описывает обе формы target'а.

## Верификация

- EditMode: `SceneEditToolsTests.Selection_SetAssetPath` (A1),
  `Selection_MissingTarget_Reported` (A2), существующий `Selection_SetThenGet` (A3).
- Живой инстанс редактора, куда пакет подключён junction'ом: `tools/list` отдаёт
  обновлённое описание (A4); вызов с двумя target'ами (реальный `.cs`-ассет +
  несуществующий путь) вернул `selected: 1`, `missing: [несуществующий]` (A1+A2).
- EditMode-прогон в Unity **не выполнялся**: тестовая сборка под
  `defineConstraints: SHTL_MCP_DEV`, инстанс `TestProject~` не поднят. Прогон — за
  ревьюером.
