# F5 — UI-дашборд

**Требование #5.** Простое функциональное окно в Unity на UI Toolkit. Чем меньше
информации — тем лучше. Идеал — информационный дашборд. Макет —
`wiki/systems/dashboard.md`.

## Acceptance criteria

- **AC5.1** — Единственное окно (`EditorWindow` на UI Toolkit). Не открывается
  автоматически/принудительно; вызывается из пункта меню.
- **AC5.2** — Показывает: светофор статуса (running/stopped), `serverName`,
  `port`, `mode` (edit/play), число подключённых клиентов, uptime.
- **AC5.3** — Готовая строка `claude mcp add …` с кнопкой **copy**.
- **AC5.4** — Предупреждение про *Reload Domain on Play* + кнопка **fix**
  (см. AC4.4).
- **AC5.5** — Хвост последних N вызовов (время, метод, статус ✓/✗, длительность).
- **AC5.6** — Кнопка **Restart server**.
- **AC5.7** — Никакой иной информации и никаких иных окон (INV-4).

## Out of scope
- Графики/профайлинг/логи целиком — это не дашборд, а инспектор. Только хвост.
